# Security policy

TIKI is an early-stage desktop application and does not yet have supported
release branches.

Please do not open a public issue for a vulnerability. Email
**peterhogg2006@gmail.com** with a description, reproduction steps and the
affected version or commit. You should receive an acknowledgement within seven
days.

TIKI opens user-selected image and NumPy files. Treat files from untrusted
sources cautiously and never load pickled NumPy object arrays.
